Render preview of Irrlicht Engine version 1.81, with experimental Vulkan and DirectX 11 renderer attached.

# Build
```
git clone https://github.com/DeviousMalcontent/Irrlicht-vkdx11.git
cd Irrlicht
mkdir build && cd build
cmake -DCMAKE_BUILD_TYPE=Release ..
cmake --build . --parallel 
```
